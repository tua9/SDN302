# Web Development Roles and Practices

> A concise overview of common web development roles, back-end skills, and modern delivery practices.

## 1. Role Comparison

| Role           | Main responsibility                                                                                       | Languages                                        | Frameworks                                         | Typical tools                                         |
| :------------- | :-------------------------------------------------------------------------------------------------------- | :----------------------------------------------- | :------------------------------------------------- | :---------------------------------------------------- |
| **Front-End**  | Builds the interface and browser experience, including layout, accessibility and client-side performance. | HTML, CSS, JavaScript, TypeScript                | React, Angular, Vue                                | VS Code, DevTools, npm, Figma, Git                    |
| **Back-End**   | Builds business logic, APIs, authentication, data processing and database integrations.                   | JavaScript/TypeScript, Python, Java, C#, Go, PHP | Express, NestJS, Django, Spring Boot, ASP.NET Core | Postman, Docker, database clients, logging tools      |
| **Full-Stack** | Connects the interface, server, database and deployment into one complete application.                    | JavaScript/TypeScript plus Python, Java or C#    | Next.js, MERN, MEAN, Laravel, Django + React       | VS Code, GitHub, Docker, CI/CD tools, cloud platforms |

## 2. Five Essential Back-End Skills

| Skill                                 | Why it matters                                                                                           |
| :------------------------------------ | :------------------------------------------------------------------------------------------------------- |
| **Programming and problem solving**   | Produces reliable business rules, handles edge cases and keeps code maintainable.                        |
| **API design**                        | Gives front-end clients and other services a predictable way to use application features.                |
| **Database management**               | Keeps data accurate and applications responsive through good schemas, queries, indexes and transactions. |
| **Security**                          | Protects users and systems through authentication, authorization, validation and secure secret handling. |
| **Testing, debugging and deployment** | Helps locate defects quickly and release changes safely and repeatedly.                                  |

## 3. Hosting and CI/CD

### Web Hosting

Web hosting stores an application and makes it available on the internet. A hosting provider supplies computing resources, networking, domain support and often deployment tools. **Vercel** is a popular hosting service for modern front-end and full-stack JavaScript applications.

### CI/CD

CI/CD means **Continuous Integration** and **Continuous Delivery or Deployment**. A pipeline automatically builds and tests code after changes are pushed, then prepares or releases the application. This reduces manual errors and makes delivery faster and more repeatable. **GitHub Actions** is a popular CI/CD service.

---

**Key idea:** Front-end focuses on the user experience, back-end focuses on server-side functionality and data, and full-stack combines both areas.
